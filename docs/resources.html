1. Query tags for cost attribution

  • Query tags overview, with setup for each tool
  • dbt: dbt-databricks 1.11+ adds @@dbt_model_name and other tags automatically, and you can add your own per project or per model.
  • SET QUERY_TAGS syntax
  • Query history system table: tags land in the query_tags column.

Tableau: set tags through Initial SQL. Example (test it on one workbook first):

SET QUERY_TAGS['tool'] = 'tableau', QUERY_TAGS['workbook'] = [WorkbookName], QUERY_TAGS['user'] = [TableauServerUser];

The Tableau parameters you can use are listed in Initial SQL parameters.

CI builds: set query_tags on the CI target in profiles.yml, for example:

query_tags: '{"env": "ci", "pr": "{{ env_var(''PR_NUMBER'', ''none'') }}"}'

For CI scripts that use the Python connector, pass query_tags when you open the connection.
